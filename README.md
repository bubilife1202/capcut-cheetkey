# CapCut Cheat Key 🎬

**30년차 에디터의 시크릿 아카이브**

캡컷(CapCut) 사용자를 위한 실전 편집 노하우와 무료 우회법을 제공하는 웹 아카이브입니다.

## 🎯 프로젝트 목표

- **Zero Cost, High Quality**: 유료 기능 없이 무료 기능 조합으로 프로급 퀄리티 달성
- **Instant Action**: 긴 튜토리얼 대신 즉시 적용 가능한 설정값 제공
- **Verified Source**: 실제 타임라인에서 검증된 노하우만 엄선

## ✨ 주요 기능

- 📋 **5가지 핵심 치트키**: 자막, 색보정, 모션 블러, 단축키, 비트 싱크
- 🔍 **실시간 검색**: 키워드로 원하는 팁 빠르게 찾기
- 🏷️ **카테고리 필터**: 돈 아끼기 / 시간 단축 / 퀄리티 / 우회법
- 📋 **원클릭 복사**: 설정값을 클립보드로 즉시 복사
- 📖 **단계별 가이드**: 아코디언 형식으로 따라하기 쉽게 구성

## 🛠️ 기술 스택

- **React** (Vite) - 빠른 개발 환경
- **Tailwind CSS** - 다크 모드 스타일링
- **Lucide React** - 아이콘 라이브러리

## 🚀 시작하기

### 설치

```bash
npm install
```

### 개발 서버 실행

```bash
npm run dev
```

### 빌드

```bash
npm run build
```

### 미리보기

```bash
npm run preview
```
